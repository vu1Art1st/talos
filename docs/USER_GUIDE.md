## 1. 快速上手

### 1.1 平台简介

Talos 是一个漏洞全生命周期管理平台，覆盖「漏洞发现 → 提交 → 状态流转 → 复测闭环 → 报告输出」的完整流程，并配套资产台账、专项测试工单（渗透测试 / 漏扫基线 / 远程检测 / 春耕行动）、统计看板与开放 API 集成能力。

### 1.2 登录

**入口**：浏览器打开平台地址，未登录访问任意页面都会自动跳转到登录页。

**操作步骤**：

1. 输入**用户名**、**密码**（字段留空失焦会行内提示「请输入用户名」/「请输入密码」；密码框可点小眼睛切换明文）。
2. 可勾选**记住我**：下次打开登录页自动回填用户名；取消勾选即清除记忆。
3. 点击**登 录**（或在输入框内按回车，效果相同）。

**预期结果**：

- 成功：跳转到登录前想访问的页面，默认进入「安全态势」看板。
- 密码错误：提示「用户名或密码错误」。同一用户名在同一网络环境下 **15 分钟内累计失败 10 次**会触发锁定，提示「登录失败次数过多，请稍后再试」，期间无法登录。
- 账号被管理员禁用：提示「账号已禁用」，请联系管理员。

### 1.3 修改密码与首次登录强制改密

**入口**：右上角头像 → **修改密码**。

**操作步骤**：在弹窗中填写**原密码**与**新密码**（至少 8 位，不足会提示「新密码至少 8 位」），点**保存**。

**预期结果**：提示「密码修改成功，请重新登录」，系统自动退出并回到登录页，需用新密码重新登录。

**首次登录 / 密码被重置**：登录后系统会强制弹出修改密码弹窗（带黄条提示「首次登录或密码已重置，请先修改密码后再使用系统」），该弹窗**无法关闭**，必须完成改密后才能使用系统。

### 1.4 界面布局与全局操作

- **左侧导航栏**：按所分配角色的权限显示菜单。点底部**「收起侧栏」**收窄为只显图标（悬停有中文提示），再点展开；折叠状态会记住，窗口较窄（<1024px）时自动折叠。
- **主题切换**：顶栏月亮/太阳图标按钮，点击在暗黑 / 浅色主题间切换并持久保存，图表配色同步重建。
- **命令面板**：点顶栏**「搜索或跳转…」**或按 `⌘K`（Mac）/ `Ctrl+K`（Windows）唤起，再按一次关闭。支持：
  - **搜索结果**：输入关键词（防抖自动搜索，无需回车），最多返回 8 条，覆盖**漏洞、资产、工单、报告**四类对象，回车直达对应详情页；
  - **快速跳转**：按权限过滤的全部菜单项（含 Word 导入、访问令牌）；
  - **操作**：切换浅色 / 暗黑模式。
  - 键盘操作：`↑` `↓` 选择、`↵` 打开、`esc` 关闭；无结果时显示「没有匹配的结果」。
- **头像菜单**：访问令牌、修改密码、退出登录。
- **登录态维护**：令牌临近过期自动续期，无需手动重新登录。

### 1.5 菜单与权限对照

| 权限 key | 可见菜单 / 能力 |
|---|---|
| （所有登录用户） | 安全态势、历史漏洞库、漏洞模板库 |
| `vuln:submit` | 提交漏洞按钮 |
| `vuln:audit` | 漏洞状态流转 |
| `vuln:manage` | 批量删除漏洞、存为模板、模板库写操作、新增漏洞类型 |
| `report:manage` | 报告中心 |
| `import:manage` | Word 导入 |
| `asset:manage` | 资产台账、组织管理 |
| `special:manage` | 渗透测试工单、漏扫基线工单、远程检测、春耕行动 |
| `user:manage` | 用户管理、权限管理 |
| `system:manage` | 审计日志、通知渠道 |

## 2. 安全态势看板

**入口**：侧栏「安全态势」，登录后默认首页。

**页面内容**：

- **筛选工具栏**：「按时间筛选」日期范围（提交起 / 提交止）+ 下拉**全部部门**（可搜索）、**全部来源**、**全部等级** + **重置**按钮（有筛选时才出现）。
- **4 张统计卡**（带迷你趋势线）：漏洞总数、未闭环漏洞、修复率、在管资产。
- **近 12 个月漏洞趋势**：折线面积图，图例「提交 / 修复完成」。
- **漏洞等级分布**：环形图，环心为漏洞总数。
- **漏洞类型 Top10**：横条排行。
- **漏洞状态分布**：堆叠横条 + 图例。
- **各部门安全概况**：按渗透测试工单所属部门统计的组合图 + 明细表（部门 / 提测次数 / 发现漏洞 / 高危及以上 / 已修复 / 未闭环 / 占用人天 / 修复率，未闭环 >0 红色显示）。

**操作与预期结果**：

- 修改任一筛选条件 → 所有统计卡、图表、表格**立即**按条件刷新。
- 点**重置** → 清空全部筛选，恢复全量数据。

## 3. 漏洞管理

### 3.1 历史漏洞库（漏洞列表）

**入口**：侧栏「历史漏洞库」。

**搜索与筛选**：

1. 顶部搜索框占位**「搜索标题 / 系统 / URL」**，回车触发检索，点 × 清空也会刷新。
2. 点**筛选**按钮（激活时变主色并显示条件数徽标）打开筛选面板，字段：**状态 / 等级 / 类型 / 系统类型 / 测试类型 / 选择资产 / 归属部门 / 录入时间**（日期区间），均为可多选下拉；面板底部有**「只看我提交的」**复选框和**「重置筛选」**文字按钮。
3. **预期结果**：勾选任何条件后列表**实时联动刷新**（无需点查询按钮）；「重置筛选」清空全部条件（保留搜索关键字）。

**统计概览**（折叠面板，与筛选条件联动实时更新）：展开后显示 **7 张卡片**（漏洞总数 / 严重 / 高危 / 中危 / 低危 / 已修复 / 修复率）和**漏洞统计透视表**（行 = 部门 → 系统，列 = 各等级的数量 / 已修复 / 未修复，底部自动合计；表头旁动态显示当前生效的筛选标签）。

**列表操作**：

- **查看详情**：点击任意行 → 跳转漏洞详情页。
- **提交漏洞**：点右上主按钮「提交漏洞」（需 `vuln:submit` 权限）→ 进入新建页。
- **批量删除**（需 `vuln:manage`）：勾选多行 → 点红色**「删除选中 (N)」** → 确认框「确认删除选中的 N 个漏洞？删除后不可恢复」→ **预期结果**：提示「已删除 N 个漏洞」，列表与统计刷新；若当前页被删空自动回退一页。

**列说明**：漏洞名称 / 等级 / 类型 / 状态 / 漏洞来源 / 关联资产 / 归属部门 / 提交时间，部分列头可点击排序。「复测未通过」不是独立状态，是「修复中 + 经历过复测」的展示标签（玫红色）；来源为关联工单的漏洞恒显示「渗透测试工单」。

### 3.2 提交 / 编辑漏洞

**入口**：列表页「提交漏洞」→ `/vulns/new`；编辑从漏洞详情页点「编辑」。页面为左右布局：左侧滚动表单，右侧固定「操作」卡片。新建模式下可点**「新增漏洞」**追加多个漏洞卡片，一次提交批量入库。

**字段说明**：

| 字段 | 必填 | 说明 |
|---|---|---|
| 测试目标 | ✅ | 多选资产（远程搜索）。未搜到时下拉内可直接点**「新建资产「关键词」」**就地建资产；也可点**「新增资产」**打开资产弹窗。选中后行内提示该资产的部门 / 负责人 / URL |
| 关联渗透测试工单 | 可选 | 选中后**漏洞来源自动固定为「渗透测试工单」**（灰色不可改） |
| 漏洞名称 | ✅ | 如「后台登录接口存在SQL注入」 |
| 漏洞等级 | 默认中危 | 严重 / 高危 / 中危 / 低危 |
| 漏洞类型 | — | 可搜索下拉；管理员可在下拉底部**「新增漏洞类型」**，保存后提示「漏洞类型已新增」并自动选中 |
| 所在层 | — | 代码 / 运维 |
| 影响URL | — | 多行输入，「添加URL」增行；选中资产后**自动带入首个资产的 URL**（手动清空过则不覆盖） |
| CVSS 3.1 | — | 计算器，见下 |
| 漏洞描述 / 复现步骤 / 修复建议 | — | 富文本编辑器（支持加粗、列表、表格、代码块、插入图片、粘贴截图自动上传） |

**CVSS 计算器用法**：依次选择 8 个指标——攻击途径 / 攻击复杂度 / 所需权限 / 用户交互 / 影响范围 / 机密性影响 / 完整性影响 / 可用性影响。**预期结果**：8 项选全后实时显示评分大数字（按等级配色）、严重度标签与向量串（如 `CVSS:3.1/AV:N/…`）；未选全时提示「请完整选择 8 项指标后计算评分」。勾选**「按评分同步等级」**（默认勾选）时，评分变化会自动改写漏洞等级（≥9 严重、≥7 高危、≥4 中危、>0 低危）。

**套用模板**：点漏洞类型旁的**「套用模板」**按钮，从漏洞模板库按当前类型取模板。

**预期结果**：

- 该类型无模板：提示「该漏洞类型暂无知识库模板」。
- 仅 1 条：直接套用；多条：弹出「选择知识库模板」选择弹窗（可搜索，卡片显示等级 + 名称 + 标签 + 摘要）。
- 若描述或修复建议已填写：先弹确认「当前已填写漏洞描述或修复建议，套用模板将覆盖这些内容，是否继续？」。
- 套用成功：提示「已套用模板「xxx」」，描述（含危害说明）、修复建议、CVSS 向量一并填入。

**保存与预期结果**：

- **编辑模式**：点**「保存」** → 提示「保存成功」，跳转到漏洞详情页。
- **新建模式**：点**「提交 N 个漏洞」** → 校验测试目标与各漏洞名称（错误红字内联在字段下方）→ 成功提示「成功提交 N 个漏洞」：单条跳该漏洞详情，多条跳回漏洞列表。
- 从渗透工单进入时（URL 带 `?plan_id=`）页面顶部显示横幅「本次录入将关联渗透测试工单「系统名」」，保存后漏洞自动挂到该工单。

### 3.3 漏洞详情与状态流转

**入口**：漏洞列表点击行，或提交后自动跳转。

**页面内容**：头部为漏洞标题 + 标签组（等级 / 类型 / 状态 / CVSS 分值悬停显示向量 / 来源）；明细区显示影响URL、关联资产、渗透测试工单（已关联时显示「已关联计划」链接）、提交时间 / 通知时间 / 闭环时间；正文卡片为漏洞描述 / 复现步骤 / 修复建议 / 复测详情（有内容才显示）；右栏为**状态流转**卡片（需 `vuln:audit` 权限）与**操作日志**时间线。

**状态流转**：在右栏输入框填写**处理意见（可选）**，点击目标状态按钮（按钮由后端按状态机返回，已修复为绿色、复测中为蓝色、修复中为橙色）。

**状态机**（当前状态 → 允许的下一步）：

```
未修复 ──→ 已忽略 / 暂不处理 / 修复中 / 复测中
已忽略 ──→ 未修复
暂不处理 ──→ 未修复 / 修复中
修复中 ──→ 复测中
复测中 ──→ 已修复 / 修复中（即复测未通过）/ 已忽略 / 暂不处理
已修复 ──→ 未修复（重新打开）/ 复测中（重新复测）
```

**预期结果**：提示「状态更新成功」，状态标签、流转按钮、操作日志同步刷新；每次流转自动写入操作日志（时间 + 操作人 + 动作 + 处理意见）。当前状态无可执行流转时显示「当前状态没有可执行的流转」。

**其他操作**：

- **编辑**（右上）：跳编辑页。⚠️ 已关联渗透测试工单的漏洞**仅工单认领人**可编辑，未认领时按钮禁用并提示「仅已认领该渗透测试工单的账号可编辑该漏洞」。
- **存为模板**（管理员）：确认「将覆盖类型「xxx」已有的知识库模板，是否继续？」→ **预期结果**：提示「已存入漏洞模板库」，本漏洞的描述 / 修复建议沉淀为该类型的模板。

### 3.4 复测处理

**入口**：漏洞**编辑页**右侧操作栏的**「复测」**按钮 → `/vulns/{id}/retest`（详情页不直接提供复测入口）。

**操作步骤**：

1. 点底部**「新增复测记录」**打开弹窗（640px）。
2. 填写**复测标题**（选填，留空按创建日期自动生成如「复测记录250815」）与**漏洞修复详情**（富文本）。
3. 可选选择**复测结论**：复测未修复 / 已修复。灰字提示「选择结论将同步调整漏洞状态（须处于复测中，且必须先填写复测详情）」。
4. 点**保存**。

**预期结果**：

- 提示「复测记录已新增」，新卡片出现在列表，顶部「共 N 条复测记录」计数 +1。
- 若选择了结论且漏洞处于「复测中」：漏洞状态被同步改为**已修复**或**复测未通过**；只填结论不填详情会被拦截：「选择复测结论前请先填写复测详情」。
- 修改记录：点卡片标题可改名（回车保存，提示「复测记录标题已更新」）；编辑富文本后点**保存**提示「复测记录已保存」；**删除**走气泡确认「确认删除该复测记录？」，成功后卡片消失、计数 -1。

## 4. 漏洞模板库

**入口**：侧栏「漏洞模板库」。沉淀标准漏洞描述，提交漏洞与 Word 导入时可自动套用。

### 4.1 新建 / 编辑条目

点**「新建条目」**（需 `vuln:manage`）打开 800px 弹窗：

| 字段 | 必填 | 说明 |
|---|---|---|
| 漏洞名称 | ✅ | 如「SQL注入」「SSRF服务器端请求伪造」 |
| 漏洞类型 | ✅ | 可搜索下拉，底部「新增」可即时扩展类型 |
| 危害等级 | ✅ | 默认中危 |
| CVSS向量 | 可选 | 输入合法向量时右侧**实时显示评分大数字与等级色标签** |
| 标准描述 / 危害说明 / 修复建议 | — | 富文本 |
| 参考链接 | — | 每行一个，如 `https://owasp.org/Top10/` |

**预期结果**：点**保存**提示「保存成功」，弹窗关闭、列表刷新（新建按名称去重覆盖）。

### 4.2 JSON 批量导入

1. 点**「批量导入」**打开弹窗；点**「选择 JSON 文件」**将文件内容填入文本框，或直接粘贴 JSON；点**「下载示例模板」**可获取一份完整的 SQL注入示例（`knowledge-import-template.json`）。
2. JSON 要求：条目**数组**，按「漏洞名称」匹配——已存在则覆盖；单次至多 **500 条**；必填 `vulnerability_name`（漏洞名称）、`vul_type`（类型码）、`severity_level`（等级码）；可选 `description_html / harm_html / solution_html / references`。
3. 点**导入**。

**预期结果**：格式错误提示「JSON 格式错误，请检查后重试」；非数组提示「导入数据必须是非空的条目数组」；成功提示**「导入完成：新增 X 条，更新 Y 条」**并刷新列表。

### 4.3 删除

- 行内**删除** → 气泡确认「确认删除该条目？」→「删除成功」。
- 勾选多行后点**「批量删除 (N)」** → 确认框 →「已删除 X 条」。

### 4.4 官方模板数据同步（运维）

平台内置一份经过整理的官方模板数据集 `backend/knowledge-import-vulnerabilities.json`，条目按「漏洞名称」维护，
有明确编号的漏洞在名称后附带 CVE（如 `Spring Cloud Gateway命令执行（CVE-2022-22947）`），多漏洞组件
（Nacos / Shiro / Fastjson 等）按单个漏洞拆分，修复建议多条时按 `1、2、3` 编号换行。

同步命令在 `backend` 目录下（容器内在 `/app`）执行：

```bash
python -m scripts.sync_knowledge_templates --dry-run --prune   # 试运行，仅打印新建 / 更新 / 清理明细
python -m scripts.sync_knowledge_templates --prune             # 正式同步（幂等，可重复执行）
```

- 默认仅按名称 **upsert**（不删除条目）；`--prune` 会删除数据文件中不存在的存量条目，
  用于清理名称优化（补 CVE 编号、拆分组件）后遗留的旧名称条目。
- docker 部署下可用 `docker exec <api容器名> python -m scripts.sync_knowledge_templates --prune` 执行。

   **预期结果**：提示「解析完成，报告含 X 个漏洞」（未解析到时提示「附件上传成功，未解析到漏洞」）；**对应系统与年度自动回填**（仅当该字段为空时，已填不会被覆盖）；表单下方出现解析结果框，每条漏洞为复选项（等级标签 + 标题），**默认全部勾选**，支持全选。
3. 填对应系统、年度、阶段（如「第一阶段」）。
4. **涉及漏洞**：多选下拉可选漏洞库已有漏洞；或点**「直接新增漏洞」**展开内联小表单（名称必填 / 等级 / 类型）→ 点**「新增并关联」**→ 提示「漏洞已新增并关联」，该漏洞来源固定标记为「春耕行动」。
5. 填资产认定原因（≤255 字）、申诉成功开关、预估扣分 / 最终扣分（步进 0.5）、公文文号。
6. 点**保存**。

**预期结果**：勾选的解析漏洞由系统批量创建并自动关联到本条记录，保存成功后解析草稿清空（防止重复导入）；列表的「涉及漏洞 / 网络层级 / 危害程度」列立即体现新关联（按关联漏洞聚合展示，超出部分显示「+N」悬停展开）。列表「原始报告」列可下载已上传的 Word；删除走气泡确认。

## 10. 报告中心

### 10.1 报告列表

**入口**：侧栏「报告中心」（需 `report:manage`）。搜索占位「搜索报告标题 / 测试系统」。

**从漏洞生成报告**：

1. 点**「从漏洞生成」**→ 弹窗填**关联渗透测试工单**（可选）、**报告标题**、**选择漏洞**（多选）。
2. **预期结果**：选定工单后，漏洞列表自动刷新为该工单漏洞并**默认全选**，标题为空时自动预填「yyyymmdd + 测试系统 + 渗透测试报告」。
3. 点**「生成」**（标题为空或未选漏洞时置灰）。若与历史报告的标题、归属工单、所选漏洞及漏洞编辑快照完全一致，弹黄色确认框「生成高度相似报告」（仍要生成 / 取消）。
4. **预期结果**：提示「报告已生成」，自动跳转报告编辑页。后台自动联动：每个漏洞生成一个章节；关联漏洞流转为「修复中」；工单进入等待复测阶段并记录初测完成时间。

**新建空白报告**：点「新建空白报告」→ 直接创建「未命名报告」并跳编辑页。

**发起复测**（行内「复测」按钮）：**预期结果**：提示「已发起复测，已自动生成复测报告」并跳转新复测报告编辑页。规则：复测报告标题 = 当天日期 + 原标题改为「渗透测试复测报告」；同日重复发起自动加「-1」「-2」后缀；若上一次复测后漏洞与内容均无变化会被拒绝：「复测结果未更新，无需生成新的复测报告」；未修复漏洞流转「复测中」，工单进入「复测中」并新增复测轮次（删除复测报告时轮次回退）。

**批量导出 zip**：勾选多行 → 点**「批量下载（N）」**。

**预期结果**：系统逐份复用或新建导出任务，前端轮询（约最长 3 分钟），全部完成后自动下载「测试报告批量下载.zip」（内含各「报告标题.docx」）。部分失败提示「部分报告导出失败（N 份），已跳过失败项」仍下载成功部分；全部失败提示「所选报告均导出失败，请检查后重试」。

**目录域提醒**：导出的 Word 若目录域为占位，会弹出「报告待办」提示：在 Word 中全选（Ctrl+A）后按 **F9** 或右键目录「更新域 → 更新整个目录」即可生成目录；可勾选「不再显示此提示」。

**导出记录管理**：点击**报告标题文字**展开该行导出历史（首次懒加载），每条含格式（DOCX / PDF）、状态（生成中 / 已完成 / 失败，失败悬停看原因）与操作：**下载**（仅已完成）、**删除**（气泡「确认删除该导出记录？文件将一并移除」）。删除报告时其全部导出记录与文件一并删除。

### 10.2 报告编辑

**入口**：报告列表「编辑」，或生成报告后自动跳转。

**报告信息卡片**：报告标题、测试系统、归属单位、报告作者（多选）、测试周期（日期范围）、实际人天、被测系统IP、被测测试账号。

- **实际人天自动计算**：= 结束日期 − 开始日期 + 1（含首尾），随日期联动，不可手填。
- **自动保存**：修改任意字段后头部状态变「有未保存修改」，**3 秒防抖自动保存草稿**；也可点「保存报告」手动保存 → 提示「保存成功」，版本号 +1。
- **版本冲突**：若他人先保存过，弹确认框「报告已被他人修改，是否加载最新版本？（当前未保存修改将丢失）」→ 加载最新 / 继续编辑。
- **定稿回退**：已定稿（final）的报告内容变更保存后**自动回退为草稿**，需重新定稿导出。
- **状态设置**：右侧栏状态下拉可切换草稿 / 已定稿。

**章节管理**：

- 每章节一张卡片：章节标题输入框 + **「上移」/「下移」**（边界置灰）+ **「删除」**（删除后 3 秒自动保存草稿）。
- **章节导航**（右栏）：点击平滑滚动定位；**支持拖拽排序**——拖到目标上半插前面、下半插后面，蓝色指示线提示插入位置。
- **新增章节**：通过「录入漏洞」按钮打开漏洞表单弹窗（自动预关联本报告的测试计划）→ 保存提示「漏洞已录入」，保存报告后新章节出现。
- **关联漏洞章节**内可直接修改漏洞的类型 / 等级 / 状态下拉——**即时保存到漏洞记录**并提示（如「漏洞状态已更新为「已修复」」）；含复测面板，操作同 3.4 节。

**导出 Word / PDF**：

1. 点右栏**「导出 Word」**或**「导出 PDF」**（有未保存修改会先自动保存）。
2. **重复导出确认**：若与最近一次同格式导出的内容指纹完全一致，弹「检测到重复导出」确认框（列出报告 / 格式 / 版本 / 已存在记录时间），点「继续导出」或「取消」。
3. **预期结果**：提示「导出任务已提交，生成完成后可在导出记录中下载」；「导出记录」卡片出现黄色「生成中」条目，每 2 秒自动轮询直至「已完成」（可下载）或「失败」（悬停看原因）。
4. 导出时若测试周期为空，系统自动预填（开始 = 关联漏洞最早提交日期，结束 = 当天）并重算实际人天。

**PDF 预览**：导出记录点**「预览」**→ 800px 弹窗内嵌展示（docx 会后台临时转 PDF，加载失败提示「预览加载失败，请确认转换服务可用」）。

### 10.3 Word 报告导入

**入口**：报告中心「Word 导入」按钮或侧栏「Word 导入」（需 `import:manage`）。将既有 Word 渗透 / 复测报告解析入库。

**① 上传与解析**（批次列表页）：

1. 点**「下载导入模板」**获取「漏洞导入模板.docx」，按模板整理报告（表格行标签：漏洞名称 / 漏洞等级 / 漏洞类型 / 漏洞链接 / 漏洞描述 / 漏洞证明 / 修复建议；旧模板的「影响URL / 复现步骤」标签也兼容）。
2. 拖拽或点选 .docx 文件（**单次最多 20 份**，单份 ≤50MB，仅 .docx）→ 点**「开始上传（N 份）」**。
   **预期结果**：全部成功提示「成功上传 N 份报告，后台解析中」；部分失败逐个提示原因并汇总「上传完成：成功 X 份，失败 Y 份」。
3. 存在解析中的批次时列表**每 2 秒自动刷新**；状态流转：排队中 → 解析中 → 待确认（失败时显示原因）。
4. 行内**「预览」**：弹 PDF 预览窗查看原 Word 内容。

**② 预览确认（单批次）**：行内点**「预览确认」**进入批次详情页：

- 顶部三个关联选框：**关联渗透测试工单（可选）/ 入库到已有资产（可选）/ 关联到报告（可选）**。选定工单后资产选框自动联动为工单下首个资产。
- 每条解析记录一张卡片（默认全选待确认记录）：
  - **修正**：展开表单修正漏洞名称 / 等级 / 类型 / 影响URL → 保存提示「修正已保存」（解析异常的记录补上标题后自动回到「待确认」）。
  - **丢弃**：记录直接变「已丢弃」（卡片半透明），不再入库。
  - **查看漏洞**：已入库记录可跳转查看。
- 点**「确认入库（N 条）」**→ **预期结果**：提示「成功处理 N 条漏洞记录」（关联了工单追加「已关联测试计划…」，自动生成报告再追加「已生成报告…」）。

**后台自动行为**：报告格式批次未选工单时，按解析出的系统名**自动匹配 / 创建渗透测试工单与资产**，并自动生成对应报告（复测报告进入对应复测轮次）；同一工单下相同名称的漏洞**自动去重合并**（复测记录更新原漏洞状态与复测详情）；自动生成的报告同步产出一条「已完成」的导出记录。

**③ 批量关联工单并确认（多批次合并）**：勾选多个「待确认」批次 → 点**「批量关联工单并确认（N）」**→ 弹窗选关联工单 / 资产 → 点「确认入库」。

**预期结果**：按「报告日期旧 → 新」顺序处理（保证最新复测报告的「已修复」状态最终生效）；结果提示「确认完成：成功 X 个 / 跳过 Y 个 / 失败 Z 个」并逐行列出失败原因；单批失败不影响其他批次。

## 11. 系统管理（管理员）

### 11.1 用户管理

**入口**：侧栏「系统管理 → 用户管理」（需 `user:manage`）。

**新建 / 编辑用户**（480px 弹窗）：用户名（编辑时禁改）、密码（编辑时留空表示不修改）、姓名、邮箱、角色（可清空）、状态开关（正常 / 禁用）。保存提示「保存成功」。

**预期结果**：

- 新建用户后即可用该账号登录；重置密码后，用户下次登录会被**强制要求改密**。
- 状态设为禁用后该账号登录被拒（「账号已禁用」）。

**查看权限**：行内「查看权限」→ 弹窗按功能模块分组展示权限标签（蓝色 = 拥有，灰色 = 没有，悬停看说明）；角色含 `*` 时顶部显示黄条「该用户角色拥有全部权限（*）」。

**删除**：气泡确认「确认删除该用户？」→「删除成功」。

### 11.2 权限管理（角色）

**入口**：侧栏「权限管理」。基于角色的权限配置，控制菜单显示与操作范围。

**操作步骤**：点**「新建角色」**→ 填角色名称（必填）→ 在**权限配置**区勾选权限（按模块分组，支持**「全选」/「清空」**与每组标题行的「全选本组」，权限名后问号悬停显示说明）→ 填备注 → 保存。

**预期结果**：提示「保存成功」；该角色用户的菜单显隐与操作可用性**立即**按新权限生效。列表中权限 `*` 显示红色「全部权限」标签，否则显示前 3 个权限 + 「+N」悬停展开。

### 11.3 审计日志

**入口**：侧栏「审计日志」（需 `system:manage`）。登录事件与敏感操作记录。

**操作步骤**：三个页签——**登录日志**（默认）/ **操作日志** / **全部**（切换即自动查询）；筛选条件：用户名、动作下拉（登录页签下仅显示登录类动作）、IP、日期范围 → 点**「查询」**。

**预期结果**：列表按时间倒序展示，动作带彩色标签（登录成功绿色，删除 / 吊销类红色，创建 / 流转 / 认领类蓝色）；详情列将 JSON 展平为「键: 值」文本。记录范围包括：登录成功 / 失败 / 锁定、修改密码、用户与角色操作、漏洞创建 / 删除 / 流转、工单流转 / 认领 / 创建 / 编辑、报告导出 / 删除、导入入库、知识库删除、令牌创建 / 吊销、通知渠道变更。

### 11.4 通知渠道

**入口**：侧栏「通知渠道」（需 `system:manage`）。将平台事件推送到企业微信、钉钉或邮箱。

**新建 / 编辑渠道**（640px 弹窗）：

| 字段 | 说明 |
|---|---|
| 名称 | ✅ 必填，如「安全群机器人」 |
| 类型 | 企业微信 / 钉钉 / 邮件（**编辑时禁改**） |
| Webhook 或收件邮箱 | 企业微信 / 钉钉填 Webhook 地址；邮件填收件邮箱（每行一个） |
| 订阅事件 | 复选：漏洞创建 / 工单认领 / 漏洞状态流转 / 复测完成（至少选一个） |
| 启用 | 开关，默认开 |

**预期结果**：保存提示「保存成功」。列表中**「启用」开关即时生效**（提示「已启用」/「已停用」）；点**「测试发送」**向该渠道发一条测试消息验证连通性，配置错误会返回对应失败提示。

## 12. 开放 API 与个人访问令牌

### 12.1 个人访问令牌（PAT）

**入口**：右上角头像 → **访问令牌**，或命令面板跳转。供内部看板与脚本调用开放 API。

**创建步骤**：

1. 点**「新建令牌」**→ 填**名称**（必填，如「安全大屏看板」），选**有效期**（7 天 / 30 天 / 90 天 / 365 天，默认 30 天）→ 点「创建」。
2. **预期结果**：弹出**一次性复制弹窗**，顶部黄条警告「请立即复制保存：明文令牌仅此一次展示，关闭后无法再查看」→ 点**「复制令牌」**提示「已复制到剪贴板」。关闭后明文不可再查，列表仅显示令牌前缀。

**其他操作**：

- **吊销**：气泡确认「吊销后无法恢复，确认吊销？」→ 提示「已吊销」。过期令牌列表中标灰「已过期」。令牌创建与吊销均记入审计日志。
- **接口文档**：列表页按钮，打开内嵌的开放 API 指南。

### 12.2 开放 API 概述

使用 PAT 认证（请求头携带令牌）调用：

- **只读**：`/open-api/vulns`（漏洞列表）、`/open-api/stats`（统计聚合）。
- **读写**：渗透测试工单与漏扫基线工单的查询、创建、更新，供外部系统对接。

鉴权方式、参数与调用示例详见 [OPEN_API_GUIDE.md](./OPEN_API_GUIDE.md)。

### 漏洞状态

未修复 / 修复中 / 复测中 / 已修复 / 已忽略 / 暂不处理。流转规则见 [3.3 节](#33-漏洞详情与状态流转)。「复测未通过」为「修复中 + 经历过复测」的展示标签。

### 漏洞类型

SQL注入、XSS跨站、命令执行、代码执行、文件包含、任意文件操作、权限绕过、逻辑漏洞、存在后门、信息泄露、文件上传、弱口令、威胁情报、其他。管理员可在漏洞表单 / 模板库中动态扩展新类型。

### 漏洞来源

工信部远程检测、春耕行动、集团众测、集团ASM远程检测、数智事业部远程检测；关联渗透工单的漏洞来源固定展示为「渗透测试工单」。

### 渗透工单状态

未测试 → 初测中 → 等待复测 → 复测申请 → 复测中 → 复测完成；「测试通过」为无漏洞结项终态。详见 6.4 节。

### 漏扫测试项状态

未开始 / 初测中 / 等待复测 / 复测中 / 复测完成 / 忽略。操作对照见 7.3 节。

### 报告状态

草稿（draft）/ 已定稿（final）/ 已完成（completed，全部关联漏洞闭环）。已定稿报告再编辑保存会自动回退为草稿。

### Word 导入批次状态

排队中 → 解析中 → 待确认 → 已入库；失败为「解析失败」。记录级状态：待确认 / 解析异常 / 已入库 / 已丢弃。

### 导出任务状态

生成中（排队中 / 执行中）→ 已完成 / 失败。

## 附录 B：常见问题

**Q：登录时提示「登录失败次数过多」？**
同一用户名在 15 分钟内累计输错 10 次会触发锁定保护，请稍后重试或联系管理员。

**Q：登录后看不到某些菜单 / 按钮？**
界面按角色权限显示。联系管理员在「权限管理」中为你的角色勾选对应权限。常见对应关系：看不到「报告中心」缺 `report:manage`；漏洞不能流转缺 `vuln:audit`；没有「提交漏洞」按钮缺 `vuln:submit`。

**Q：为什么强制修改密码？**
首次登录或密码被管理员重置后必须先改密才能使用系统。

**Q：渗透工单的漏洞不能编辑？**
已关联渗透测试工单的漏洞仅**工单认领人**可编辑，请先在工单流程抽屉中「认领」；未关联工单的漏洞由提交人或漏洞管理员编辑。

**Q：状态流转按钮不见了？**
状态流转受状态机约束（见 3.3 节），只有当前状态允许的目标状态会出现按钮；同时需要 `vuln:audit` 权限。

**Q：「复测未通过」是什么状态？**
不是独立状态，是「修复中 + 经历过复测」的展示标签，表示最近一轮复测未通过、漏洞已退回修复中。

**Q：个人访问令牌忘了保存怎么办？**
明文令牌仅在创建时展示一次，无法再次查看。吊销旧令牌后重新创建即可。

**Q：Word 导入解析失败 / 没解析出漏洞？**
确认使用平台提供的标准模板（Word 导入页可下载），检查漏洞信息表格的行标签是否为「漏洞名称 / 漏洞等级 / 漏洞类型 / 漏洞链接 / 漏洞描述 / 漏洞证明 / 修复建议」；文件必须是 .docx 且不超过 50MB；失败原因显示在批次列表中。

**Q：导出的 Word 报告目录是占位文字？**
在 Word 中全选（Ctrl+A）后按 F9，或右键目录 →「更新域」→「更新整个目录」即可生成目录。

**Q：报告导出卡在「生成中」？**
导出为后台异步任务，大报告需要一些时间；长时间未完成或显示「失败」时，可删除该导出记录后重新发起。

**Q：生成报告时提示「高度相似」？**
系统检测到与历史报告的标题、归属工单、所选漏洞及漏洞编辑快照完全一致，防止重复报告；确认无重复后可点「仍要生成」。

**Q：保存报告时提示「版本冲突」？**
他人刚保存过该报告。选择「加载最新」会丢弃自己未保存的修改，建议先复制本地内容再加载。

**Q：已定稿的报告改了一下怎么变回草稿了？**
已定稿报告内容变更后自动回退为草稿，避免报告内容与定稿版本不一致，请重新定稿并导出。

**Q：渗透工单关联了新漏洞，为什么状态自动变了？**
「测试通过」（无漏洞结项）的工单补录或关联新漏洞时会自动重开为「初测中」，复测完成的工单漏洞回退时会重新进入「复测中」，保证状态与漏洞实际闭环情况一致。
