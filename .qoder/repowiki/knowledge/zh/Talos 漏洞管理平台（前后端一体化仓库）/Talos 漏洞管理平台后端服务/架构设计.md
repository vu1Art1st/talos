应用采用分层模块化结构：
- `app/main.py` 通过 `create_app()` 构建 FastAPI 实例，使用 `lifespan` 钩子在启动时初始化数据库连接并尝试连接 Redis（失败则降级为进程内执行）。
- `app/api/v1/` 按业务域划分路由模块（auth、users、assets、vulns、imports、reports、special、dashboard、misc），由 `__init__.py` 统一注册到 `api_router`，前缀 `/api/v1`。
- `app/core/` 提供全局配置（`config.py` 基于 pydantic-settings，支持 `VP_` 环境变量前缀）、依赖注入（`deps.py`）与安全工具（`security.py` JWT/密码哈希）。
- `app/models/` 使用 SQLAlchemy ORM 声明式模型（user、business、report、special、imports），`db.py` 管理 async engine/session 并在 `init_db()` 中幂等建表、写入默认角色与 admin 用户。
- `app/services/` 封装纯业务逻辑（docx 解析、报告构建、PDF 转换、漏洞服务、计划服务），被 API 层和 worker 层共同调用。
- `app/workers/` 基于 arq 的后台任务入口，定义 `parse_import_task`、`export_report_task`、`send_mail_task` 三个任务函数，通过 `WorkerSettings` 暴露给 arq。
- 存储通过 `StaticFiles` 挂载 `/storage`，上传与导出文件落盘由 `settings.storage_path` 统一管理。
- Alembic 用于生产环境版本化迁移，开发 SQLite 库在 `init_db()` 内通过 `_migrate_lightweight()` 做轻量列级迁移。
