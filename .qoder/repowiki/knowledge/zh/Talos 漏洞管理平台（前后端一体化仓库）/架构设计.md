仓库顶层通过 docker-compose.yml 将 backend（FastAPI API + arq worker）、frontend（Vue 3 静态资源）、postgres、redis、gotenberg 五个服务统一编排：api 与 worker 共享同一后端镜像并通过 VP_* 环境变量连接数据库、队列与文档转换服务，前端构建后由 Nginx 暴露 80 端口并反向代理 /api 与 /storage 到后端 8000 端口。dev.sh / dev.ps1 则提供轻量本地开发模式——SQLite + 禁用队列的无状态后端配合 Vite Dev Server，无需外部依赖即可启动前后端联调。前后端之间仅通过 REST API（OpenAPI/Swagger 文档位于 /api/docs）通信，无共享代码或编译期耦合。
