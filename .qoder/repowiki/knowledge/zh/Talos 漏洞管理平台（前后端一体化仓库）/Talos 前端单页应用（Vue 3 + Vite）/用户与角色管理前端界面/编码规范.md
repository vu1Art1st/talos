- 视图层统一通过 `../api/client` 发起 HTTP 请求，使用 `client.get/post/put/delete` 配合 URL 模板字符串访问 REST 资源。
- 异步操作采用 try/finally 模式包裹 loading 状态，确保无论成功失败都重置 UI 加载指示。
- 表单数据使用 `reactive` 定义初始结构，打开编辑弹窗时通过 `Object.assign` 合并行数据并清空敏感字段（如 password）。
- 用户反馈统一使用 `ElMessage.success` / `ElMessage.warning` 进行全局提示，而非 alert 或自定义弹窗。
- Pinia store 中鉴权相关状态（user、meta）通过 `localStorage` 持久化 access_token 和 refresh_token，`isLoggedIn` getter 基于 token 存在性判断登录态。
