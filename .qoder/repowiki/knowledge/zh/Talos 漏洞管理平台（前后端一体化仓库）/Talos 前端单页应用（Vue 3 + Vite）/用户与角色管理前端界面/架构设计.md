模块由三个独立的前端文件组成：`Login.vue` 负责登录入口，调用 `stores/auth.ts` 中的 `useAuthStore`（Pinia store）完成 `/auth/login` 认证并持久化 `access_token`/`refresh_token`；`UserList.vue` 是用户管理与角色权限管理的核心视图，通过 `../api/client` 直接调用 `/users`、`/roles`、`/roles/permissions` 等 REST 接口，使用本地 `ref`/`reactive` 维护表格数据、分页和弹窗表单状态。依赖方向单向：视图 → Pinia store / HTTP client，store 仅依赖 HTTP client，三者之间无循环依赖。
