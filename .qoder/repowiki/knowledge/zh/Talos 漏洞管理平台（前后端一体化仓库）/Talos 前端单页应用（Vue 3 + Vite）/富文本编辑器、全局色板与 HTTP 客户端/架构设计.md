本模块由三个相互独立的文件组成：
- `RichEditor.vue`：基于 `@tiptap/vue-3` 的 Vue 单文件组件，通过 StarterKit 及 Image/Link/Table 等扩展实现富文本编辑；通过 `update:modelValue` 与 `update:json` 两个双向绑定事件向父组件同步 HTML 与 JSON 内容；图片上传走本地 `<input type=file>` + `/upload/image` 接口。
- `colors.ts`：集中定义 `LEVEL_COLORS`、`STATUS_COLORS` 及其按中文名的映射表，并提供 `levelColor`、`statusColor` 两个取值函数作为全站唯一色源。
- `client.ts`：基于 axios 创建 baseURL 为 `/api/v1` 的实例，在请求拦截器中从 `localStorage.access_token` 注入 `Authorization: Bearer`，响应拦截器统一处理 401（去重式 refresh token 刷新、失败后清缓存并跳转 `/login`）与错误消息展示（排除 409）。
依赖方向：`RichEditor.vue` → `../api/client`；`client.ts` → `../router`；三者之间无互相引用，属于横向共享工具。
