- 所有 API 调用统一通过 `../api/client` 实例发起，使用 RESTful 路径如 `/imports`、`/reports`、`/vulns` 等，错误提示通过 `ElMessage.success` 反馈。
- 状态映射采用本地字典函数（如 `statusName`、`statusTag`、`recName`、`recTag`），将后端枚举值映射为中文显示与 Element Tag 类型。
- 分页列表通过 `ref` 维护 `items`、`total`、`page`、`loading` 等状态，`load` 函数统一封装请求与 loading 切换，在 `onMounted` 中初始化加载。
- 需要轮询的场景（导入解析、导出任务）使用 `window.setInterval` 定时刷新，并在 `onBeforeUnmount` 中清理定时器。
- 富文本内容通过自定义 `RichEditor` 组件双向绑定 `content_html` 与 `content_json`，修改时统一调用 `markDirty` 标记未保存状态并触发防抖自动保存。
