本模块由四个独立的 Vue 单文件组件构成，分别对应两条业务线：
- 导入流程：`ImportList.vue` 负责上传 .docx 模板并轮询解析批次状态；`ImportPreview.vue` 按批次展示解析出的漏洞记录，支持逐条修正、丢弃与批量确认入库。
- 报告流程：`ReportList.vue` 提供报告分页列表、从漏洞生成报告、新建空白报告；`ReportEditor.vue` 实现报告富文本编辑、章节增删排序、关联漏洞、异步导出（PDF/Word）及复测结论提交。
所有组件均通过 `../api/client` 发起 HTTP 请求，使用 `vue-router` 进行页面跳转，依赖 `../stores/auth` 获取权限与元数据，UI 统一基于 Element Plus 的 el-card/el-table/el-dialog 等组件构建。组件之间无直接 import 关系，仅通过路由和后端 API 间接协作。
