模块由三个文件构成应用启动的最小闭环：`main.ts` 作为唯一入口，通过 `createApp(App)` 挂载根组件 `App.vue`，并依次注册 Pinia、Vue Router 和 Element Plus（含中文语言包与全部图标自动注册）；`App.vue` 仅作为路由容器，使用 `<router-view />` 渲染页面级组件；`style.css` 是全局样式入口，基于 Tailwind CSS 的 `@tailwind` 指令引入 base/components/utilities，并集中定义富文本内容（`.rich-content`）与 TipTap 编辑器的统一样式。依赖方向单向：`main.ts` → `App.vue` + 各插件，`App.vue` 不反向依赖 `main.ts`，样式被 `main.ts` 一次性引入。
