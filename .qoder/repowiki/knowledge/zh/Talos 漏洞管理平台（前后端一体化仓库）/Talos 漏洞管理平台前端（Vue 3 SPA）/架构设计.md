以 `src/main.ts` 为唯一入口创建 Vue 应用实例，集中注册 Pinia、vue-router、Element Plus（含中文本地化与全部图标），并挂载全局样式 `style.css`。各业务模块按功能拆分到 `views/`（页面）、`components/`（可复用组件）、`stores/`（Pinia 状态）、`utils/`（工具函数）和 `api/client.ts`（Axios HTTP 客户端）。路由由 `router/index.ts` 统一声明，所有页面通过 `layouts/MainLayout.vue` 共享布局。跨模块依赖集中在共享层：富文本编辑器（TipTap）、全局色板（`utils/colors.ts`）以及带 Bearer Token 注入与 401 刷新重试的 Axios 实例（`api/client.ts`），被各业务视图共同消费。构建产物输出至 `dist/`，由同目录 `nginx.conf` 提供静态资源服务，Dockerfile 完成镜像打包。
