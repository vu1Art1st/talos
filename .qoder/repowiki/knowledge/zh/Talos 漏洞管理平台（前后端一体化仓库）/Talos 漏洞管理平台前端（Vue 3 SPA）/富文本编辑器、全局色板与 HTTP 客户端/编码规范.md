- 颜色常量以 `Record<number, string>` 形式集中导出，并通过同名 `_BY_NAME` 映射表支持中文键访问，取值一律经 `levelColor` / `statusColor` 函数获取以保证默认回退色。
- HTTP 客户端通过 axios 拦截器统一处理鉴权：请求时注入 `Bearer access_token`，401 时去重式刷新 token 并重试一次请求，失败则清理本地令牌并跳转登录页。
- 富文本组件使用 `defineProps<{ modelValue: string }>` 配合 `emit('update:modelValue', ...)` 实现 v-model 双向绑定，同时额外暴露 `update:json` 事件同步 JSON 内容。
