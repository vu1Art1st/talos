- 所有页面组件放在 `src/views/` 下，按业务域命名（如 AssetList、VulnList、UserList），并通过 `router/index.ts` 统一注册路由
- 可复用 UI 组件放入 `src/components/`，状态管理逻辑通过 Pinia store（`src/stores/`）集中管理
- HTTP 请求统一通过 `api/client.ts` 封装的 Axios 实例发起，自动注入 Bearer Token 并处理 401 刷新重试
- 颜色与主题变量集中在 `utils/colors.ts`，各视图通过该模块获取统一的漏洞等级与状态色值
- 全局样式与 Tailwind 配置通过 `style.css` 与 `tailwind.config.js` 统一管理，Element Plus 组件库在 `main.ts` 中一次性注册
