- 所有视图在 `onMounted` 中先调用 `auth.fetchMeta()` 获取全局枚举字典，再加载业务数据，确保下拉选项与标签映射可用。
- 时间字段统一通过本地 `fmt` 函数使用 `dayjs(v).format('YYYY-MM-DD HH:mm')` 格式化，空值回退为 `-`。
- 状态与等级标签通过 `levelColor` / `statusColor` 工具函数计算颜色，并配合 `meta?.vul_level?.[code]` 等字典进行名称映射。
- API 调用统一通过 `../api/client` 发起，错误处理采用 try/finally 包裹 loading 状态，成功响应从 `data` 字段解构。
- 权限控制通过 `auth.hasPerm('vuln:submit')`、`auth.hasPerm('vuln:audit')` 等字符串标识在模板中条件渲染按钮或区块。
- 表单数据模型以 `emptyVul()` 工厂函数生成默认对象，包含 HTML 与 JSON 双字段（如 `description_html` / `description_json`），富文本通过 `RichEditor` 的 `v-model` 与 `@update:json` 同步。
