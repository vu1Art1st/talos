根目录作为编排层，不承载业务逻辑，而是通过 docker-compose.yml 定义 api、worker、frontend、postgres、redis、gotenberg 六个服务并建立依赖与健康检查；backend 与 frontend 各自独立构建镜像，由 compose 负责网络互通与端口映射。dev.sh / dev.ps1 提供本地一键开发入口，自动创建虚拟环境、安装依赖并以 SQLite + 无队列模式启动前后端，便于无需 Postgres/Redis 的纯前端调试。docs 与 scripts 分别提供用户手册/运维指南以及数据库备份、Alembic 迁移、一键升级等生产脚本，均面向同一套 Docker Compose 环境运行。所有子模块通过统一的 VP_* 环境变量约定进行配置注入，形成跨前端的配置契约。
