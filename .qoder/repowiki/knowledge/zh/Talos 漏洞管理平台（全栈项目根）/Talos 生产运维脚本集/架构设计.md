本模块由四个独立的 Bash 脚本组成，围绕 docker compose 编排的 PostgreSQL + API 服务展开：
- `backup.sh`：通过 `docker compose exec` 在 postgres 容器内执行 `pg_dump` 并 gzip 输出到 `backups/<时间戳>/db.sql.gz`，同时打包 `/app/storage` 目录为 `storage.tar.gz`。
- `restore.sh`：校验输入备份目录后，按顺序启动 postgres、导入 SQL、解压 storage 文件、拉起全部服务。
- `migrate.sh`：以临时容器运行 `python -m scripts.migrate`，复用 api 容器的环境变量与依赖执行 Alembic 迁移。
- `upgrade.sh`：聚合上述脚本的一键升级流程，支持 `--no-backup`、`--no-pull` 参数，严格按「备份 → git pull → 重建镜像 → 迁移 → 启动」顺序执行，并在迁移前确保 Alembic 先于后端 `create_all` 应用结构变更。
所有脚本均通过 `cd "$(dirname "$0")/.."` 切到仓库根目录，依赖 `.env` 与 `docker-compose.yml`，不直接操作卷名或密码，而是通过容器环境变量传递凭证。
