- 所有页面按功能划分在 `src/views/` 下，每个视图对应一个路由，布局统一由 `layouts/MainLayout.vue` 承载。
- 全局状态集中在 `src/stores/`，通过 Pinia 的 `defineStore` 创建并按需引入，避免在组件内分散维护。
- API 请求统一通过 `src/api/client.ts` 封装，组件不直接调用 axios。
- 可复用 UI 抽取到 `src/components/` 并以单文件组件（.vue）形式组织，保持视图与组件职责分离。
- 主题与图表初始化在 `main.ts` 中集中执行，确保应用启动时同步完成明/暗主题与 ECharts 主题注册。
