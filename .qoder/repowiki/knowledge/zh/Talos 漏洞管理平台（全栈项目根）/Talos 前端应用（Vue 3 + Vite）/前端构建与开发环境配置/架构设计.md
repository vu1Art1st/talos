该模块由三个核心配置文件组成：`package.json` 定义项目元数据、npm scripts（dev/build/preview）以及运行时依赖（Vue 3、Pinia、Vue Router、Element Plus、ECharts、Axios、TipTap 编辑器等）和开发依赖（Vite 5、TypeScript、Tailwind CSS 3、PostCSS）。`vite.config.ts` 通过 `@vitejs/plugin-vue` 启用 Vue SFC 支持，配置开发服务器绑定 `0.0.0.0` 并设置严格端口模式，同时通过 `/api` 和 `/storage` 路径代理到后端服务（默认 127.0.0.1:27013），端口可通过环境变量 `VP_FRONTEND_PORT` 和 `VP_BACKEND_PORT` 覆盖。`tailwind.config.js` 采用 class 模式的暗色主题切换，扩展品牌色板、卡片圆角与阴影、字体栈，并通过禁用 `preflight` 避免与 Element Plus 样式冲突。三者共同构成无额外构建脚本的轻量前端工程基座。
