应用以 `src/main.ts` 为入口统一注册 Pinia、Vue Router、Element Plus（含中文语言包与图标）、主题与 ECharts 双主题后挂载根组件 `App.vue`。
- 路由层：`router/index.ts` 定义页面路由，各业务页面位于 `views/`（如 AssetList、VulnList、ReportEditor 等），共用 `layouts/MainLayout.vue` 作为布局壳。
- 状态层：`stores/auth.ts` 与 `stores/theme.ts` 分别管理认证与明/暗主题，通过 Pinia 全局共享。
- 组件层：`components/` 提供可复用 UI（表单对话框、PDF 预览、富文本编辑器、漏洞编辑面板等），被 views 组合使用。
- 数据层：`api/client.ts` 封装 axios 请求，配合 `vite.config.ts` 中 `/api` 与 `/storage` 代理转发至后端端口。
- 工具层：`utils/chartTheme.ts`、`colors.ts`、`html.ts` 提供图表主题、颜色与 HTML 处理等跨模块能力。
- 构建与开发：Vite 默认绑定 `0.0.0.0` 并通过环境变量 `VP_FRONTEND_PORT` / `VP_BACKEND_PORT` 覆盖前后端端口，支持外部访问与本地代理联调。
